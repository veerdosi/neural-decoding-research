# Research log

## 18 November 2026, before decoding calls

Question: Does the correct held-out neural recording improve GPT-6.1 Sol's word identification over missing or trial-shuffled recordings, without a trained supervised decoder?

Access: authenticated Codex CLI returned SOL_ACCESS_OK with explicit model gpt-6.1-sol. Local catalog lists the model and API support. All experimental calls will use Codex only, as requested. No direct API calls or model substitutions.

Dataset choice: T12, 2023-08-15, motoric imagined speech, isolated verbal behaviors. Original study reports substantial decodable information in this condition. Four balanced blocks each contain seven repeats of seven words plus rest. Use blocks 8 and 9 for calibration (98 word trials); hold out blocks 17 and 25 (98 word trials). Exclude rest. No overlapping windows, trial reuse, or random within-block calibration/test splits.

Predeclared preprocessing: i6v array (64 channels), fixed 200-1200 ms post-go window, average threshold-crossing counts and log1p spike power. Standardize only on calibration trials. Compare all 128 dimensions with 12 unwhitened PCA coordinates derived from calibration inputs without labels. No optimized window, supervised feature selection, prototypes, pretrained encoders, classifier fitting, or gradient updates. Sol receives individual labeled examples and individual unlabeled inputs; the runner never computes labels from signals.

Initial conditions: PCA in-context; raw 128-feature in-context; raw zero-shot; PCA in-context with test recordings shuffled within test blocks; no query neural input with the same PCA calibration. Use identical evaluation trials. Query IDs and presentation order are randomized; do not tell Sol evaluation class counts. Every call is a fresh ephemeral context. Tools forbidden in prediction prompts; reject tool calls in evaluation. Store full inputs and final responses.

Primary evidence: PCA in-context compared with chance, no-input, and shuffled-input controls. Raw representation and zero-shot are sensitivity probes. Report all attempted conditions. A positive pilot requires above-chance signal-linked predictions in both held-out blocks, superiority to controls, and an explicit cue-confound qualification. If results are positive, prefer one targeted artifact test over expanding datasets or building a demo.

Limits known before testing: a prompted intended word is the ground truth, not an independent readout of subjective thought. Text disappears at go in the active task, but post-go activity may still reflect cue memory, preparation, or residual visual responses. Shuffled/no-input controls can establish recording-specific word information; they cannot by themselves establish that information is uniquely generated by inner speech. Only one participant and session; trial-level confidence intervals will overstate population precision.

## Initial control results

The raw-feature zero-shot call and the no-query-neural call each returned the same fixed word, ban, for all 98 test trials: 14/98 correct, 14.3%, trial-level exact 95% CI 8.0-22.8%. Their explanations explicitly state the mapping is unknown or the query signal is missing. No tool calls occurred. These outcomes are consistent with the lack of a semantic channel-to-word mapping and do not test participant-specific adaptation.

The PCA-shuffled request initially received a model-capacity error and an automatic approximately 311-second retry delay. No alternative model was requested. Other conditions continued.

## Unlabeled drift audit, before in-context results

Calibration-standardized block mean vectors have RMS magnitudes 0.138 SD in each calibration block, 0.700 SD in test block 17, and 1.050 SD in test block 25. Within-block feature SD remains about 1.0. This shows a substantial shift in feature offsets over the session without using word labels. It may challenge generalization from early blocks. A justified follow-up would subtract the same trial's pre-go neural activity before projection, which could reduce tonic drift and emphasize the production-period change. This transformation has not yet been tested.

## Representation follow-up declared before in-context results

Test whether numerical comparison, rather than the absence of neural information, limits dense-vector prompting. Create a label-free representation: mean squared Euclidean distance from each query to individual calibration recordings using the same raw128 standardized features; expose the 12 nearest reference IDs and distances plus a separate individual reference-label table. Do not calculate votes, word scores, class averages, predictions or a learned metric outside Sol. Compare correct and within-block shuffled recordings. This is similarity-assisted in-context identification, not evidence that Sol intrinsically understands arbitrary electrodes. It is within the permitted deterministic transformation and labeled-example constraint; all word decisions remain model responses. The neighborhood size is fixed before inspecting these results. No drift correction or preprocessing changes are introduced, so comparison with raw128 isolates the supplied representation.

## First in-context result

PCA12 in-context: 31/98 correct (31.6%; descriptive exact trial-level 95% CI 22.6-41.8%). Block 17: 20/49 (40.8%); block 25: 11/49 (22.4%). No query-neural baseline: 14/98; the paired discordance is 19 real-only correct versus 2 baseline-only correct (descriptive one-sided exact McNemar p=0.000111). None of 20,000 block-restricted label permutations reached the observed accuracy (plus-one Monte Carlo p=0.000050). The model described approximate variance-scaled comparisons with calibration centers and nearby examples, and noted distribution shift. No tools occurred. This is preliminary evidence; shuffled controls are still pending. The later-block decline is compatible with the measured drift but does not causally establish drift as the explanation.

## Representation results and matched control decision

Raw128 in-context: 52/98 (53.1%, exact descriptive 95% CI 42.7-63.2%); blocks 17 and 25: 29/49 and 23/49. Similarity-assisted: 38/98 (38.8%); blocks 24/49 and 14/49. Raw128 outperformed PCA by 21.4 percentage points on the same trials. The model reports recurring cross-channel pattern matching and downweighting extremes/shared shifts; this is a self-report, not a verified mechanism. Similarity did not improve on raw features, weakening the hypothesis that arithmetic load alone explains the representation effect. PCA discards 54.7% of input variance and may discard useful discriminative directions; that remains a hypothesis.

Because raw128 is now the strongest observed representation, add its matched shuffled-recording condition, using the already fixed donor permutation and identical high reasoning setting. This control was added after seeing accuracy, so report it as an adaptive follow-up. Do not change calibration, test trials, feature construction, or input hashes.

## Signal-link control and audit

Similarity-assisted predictions scored 38/98 with correct recordings, versus 17/98 after within-block shuffling. In the shuffled call, 36/98 predictions match the actual donor recording's word. This supports recording-linked rather than ID-linked predictions. Calls chose slightly different heuristic distance bandwidths (0.15 versus 0.2), illustrating run-to-run method variation; these are single calls, not a model-replicate estimate.

An independent score reconstruction using the original MATLAB cueList and trialCues agrees with every completed score. Stored raw/PCA query vectors exactly match the intended trial or shuffled donor, have only ID and neural-value fields, and preserve the frozen input hashes. No completed prediction call used a tool.

## Primary matched control completed

PCA12 shuffled: 16/98 (16.3%, descriptive 95% CI 9.6-25.2%); 32/98 predictions match the donor recording's actual word. Correct-recording PCA accuracy was 31/98, with 21 real-only correct versus 6 shuffled-only correct (descriptive one-sided exact McNemar p=0.00296). Together with the similarity condition, this supports neural-recording-linked cued-word information. No tool calls. The capacity-delayed call completed on the requested model.

## Final matched control and milestone

Raw128 shuffled: 16/98 (16.3%, descriptive 95% CI 9.6-25.2%). Crucially, 56/98 (57.1%) predictions match the supplied recording's actual donor word. The correct-recording call scored 52/98; the paired nominal-target comparison has 44 real-only correct versus 8 shuffled-only correct (descriptive one-sided exact McNemar p=0.000000202). This supports recording-specific word identification without an externally trained decoder. All eight prediction calls completed on gpt-6.1-sol through Codex at high reasoning effort; all returned 98 valid predictions and used no tools.

Decision: positive first-milestone evidence for calibration-assisted identification of prompted words, with important representation and drift effects. No zero-shot success, no unrestricted sentence reconstruction, no isolation of speech production from cue memory/preparation, and no cross-participant or repeat-call estimate. Stop here for review; do not begin the proposed next experiments.
